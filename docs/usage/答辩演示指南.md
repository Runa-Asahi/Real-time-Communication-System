# Ciallo v1.1.0 答辩演示指南

## 1. 与旧版本互不冲突

| 项目 | 旧版本（v1.0.x） | 答辩版（v1.1.0） |
|---|---|---|
| 默认端口 | 9500 | **9620** |
| 服务端数据 | 旧包内 `data\server` | 答辩版文件夹内 `data\server`（解压到新文件夹即完全独立） |
| 源码目录下脚本的数据目录 | `data-im-server` | `data-defense` |
| 客户端本地库 | `<数据根>\im-client\127.0.0.1_9500\...` | `<数据根>\im-client\127.0.0.1_9620\...` |
| Ciallo-Stop.bat | 结束全部 fanlx_app / Ciallo | **只结束本文件夹启动的进程** |

点对点直连监听端口由系统自动分配，不会和别的程序冲突。

**改端口**（优先级从高到低）：
1. 命令行：`Ciallo.bat -Port 9630`（局域网脚本同样可以加 `-Port`）
2. 环境变量：`set CIALLO_PORT=9630`
3. 文件：在包内 `data\port.txt` 里写一个端口号
4. 都没有设置时用 9620

客户端登录框里的端口默认也是 9620。如果改了端口，登录框里要填同一个端口。

## 2. 启动步骤

1. 把 `Ciallo-v1.1.0-windows-x64.zip` 解压到一个**新文件夹**，路径里最好不要有空格。
2. 双击 `Ciallo.bat`。第一次运行会初始化演示数据，并在后台启动服务端（127.0.0.1:9620），然后打开客户端。
3. 每多登录一个账号，就再双击一次 `Ciallo.bat`。服务端已经在运行时会直接复用，每次只多开一个客户端。
4. 演示结束后，双击 `Ciallo-Stop.bat`。
5. 想恢复初始演示数据：先停止，再删除包内 `data\` 文件夹，然后重新双击 `Ciallo.bat`。

局域网演示时，一台电脑运行 `Ciallo-LAN-Server.bat`，其它电脑运行 `Ciallo-LAN-Join.bat` 并输入显示的 IP。防火墙弹窗时要允许访问「专用网络」。

## 4. 本版修复（群逻辑统一由服务端管理）

| 问题 | 修复后的效果 |
|---|---|
| 可以邀请群主或已在群里的成员 | 服务端直接拒绝，并给出原因：对方是群主、已是成员、已有待处理请求，或账号不存在 |
| 一个管理员审批后，其他管理员那里仍显示 Pending | 审批结果只有服务端一份；任一管理员处理后，所有管理员实时看到 Approved/Rejected。已处理的请求再处理会提示「已被处理」 |
| 改群名、改昵称只在本地生效 | 改动写入服务端并推送：所有成员的聊天首页和群页面同步刷新，好友列表显示新昵称 |
| 新建的群不出现在首页 | 建群后，创建者和被邀请的成员首页都会立即出现新群 |
| 子群没有聊天入口 | 子群以「子群」类型出现在子群成员的聊天首页，可以正常收发消息 |
| 权限只在前端校验 | 所有群操作都由服务端按角色校验；前端也会按「我是群主/管理员/成员」禁用不可用的按钮 |
| 退群或被踢后会话还能用 | 会话标记为「已退出」并置灰；服务端同时拒绝再向该群发消息 |

## 5. 推荐演示路线（三个窗口）

开三个窗口，分别登录 A=2026001（群主）、B=2026002（管理员）、C=2026003（成员）。另外准备 D=2026004，演示审批时登录。

1. **聊天首页**：A 和 C 都能看到「子群 D1」。在里面发一条消息，对方实时收到。
2. **邀请校验**：B 邀请 2026001（群主）或 2026003（已在群里）都会被拒绝，并显示原因。
3. **多管理员审批**：A 在群页面批准 2026004 的申请，B 刷新后看到这条申请已经是 Approved。B 再点批准会提示「已被处理」。
4. **改群名**：A 修改 QQ 群 1001 的名称，B 和 C 的首页与群页面同步显示新名称。
5. **新建群**：A 新建群（例如 3001）并邀请 C 加入，A 的首页立刻出现这个群；C 接受邀请后，C 的首页也会出现。
6. **改昵称**：C 修改昵称，A 和 B 的好友列表与会话标题显示新昵称。
7. 可选：踢人、退群、转让群主、解散群、切换群特色（QQ/微信），以及密码修改后重新登录。

## 6. 已知限制与临场应对

- **好友备注**只保存在本地，这是按设计的个人备注，别人看不到。
- **控制台客户端**（`fanlx_app` 的交互菜单）里的群操作仍然写本地库，答辩请用图形客户端演示。
- **服务端连不上时**，客户端会退回本地库模式，这时的改动不会同步给别人。如果看到状态栏提示离线，先确认 `Ciallo.bat` 窗口显示服务端已就绪，再重新登录。
